# 前端维护指南

## 工程基线

renderer 使用 React、TypeScript、Ant Design 和 Umi Max，采用 Ant Design Pro 的页面、模型、服务约定。Umi 负责应用入口、路由、全局 Model 和构建；浮岛工作台使用自己的布局，Ant Design 提供基础控件。

全部依赖在根目录 `package.json` 中声明和锁定。Umi 从 `src/renderer` 启动，配置显式解析根目录的 React、ReactDOM 和 Ant Design，避免使用框架间接依赖的其他版本。主题通过 `AppearanceSystem` 中的 `ConfigProvider` 统一提供，因此不启用 Umi 的第二套 Ant Design 主题 Provider。

源码按进程和平台职责分区：

| 目录 | 负责什么 |
| --- | --- |
| `src/main` | 窗口、核心安装与监督、系统权限、文件、终端和更新 |
| `src/runtime` | 后台插件管理、转换器及数据导入 |
| `src/preload` | 向受信任页面暴露版本化、受限的桌面桥 |
| `src/renderer` | 用户看到的页面、交互与前端状态 |
| `src/shared` | 跨进程共享的类型、校验和事件投影，不依赖 UI 框架 |

## 页面里的代码放在哪里

以下路径相对于 `src/renderer`：

```text
config/
  config.ts                    Umi 构建、依赖解析、本地资源路径与安全策略
  routes.ts                    页面路由表
src/
  app.tsx                      Umi 运行时入口、全局错误边界
  global.css                   全局样式入口
  pages/
    workspace/
      index.tsx                工作台页面与常驻 Provider 装配
      components/              工作台专用的模式栏、内容区、会话标签和分隔条
  models/
    workspace.ts               Umi 全局 Model，负责创建和清理状态实例
    workspace/
      store.ts                 会话、事件、草稿及导航的状态协调器
      view.ts                  工作模式切换规则
  hooks/
    useWorkspace.ts            获取操作入口、订阅同一份工作台快照
  services/
    desktop.ts                 校验并获取 preload 提供的桌面桥
  components/
    AppErrorBoundary.tsx       应用异常时的恢复界面
  plugins/                     前端 Cordis、插槽、内置贡献、扩展加载及管理页面
  features/                    现有对话、轨迹、文件、终端、设置等业务模块
  domain/                      不依赖页面的纯数据计算和本地偏好规则
  platform/                    桌面桥的 TypeScript 契约与 Window 类型
  shared/ui/                   现有公共 UI 组件
  styles/                      主题变量、基础样式和工作台布局
```

`models/workspace.ts` 是 Umi 自动发现的 Model。其子目录中的 `store.ts` 和 `view.ts` 是实现文件，不各自注册 Model。`app.tsx` 是入口文件；不再有一个包揽页面、启动和状态的 `app/` 目录。

新增独立页面放在 `pages/<页面名>/index.tsx`，并在 `config/routes.ts` 注册。只被这个页面使用的组件就近放到页面的 `components/`；已有跨视图业务继续复用 `features/` 中的模块。只有确有跨页面消费者时，才提取公共组件或全局 Model。

工作台页面组件按区域组织。中央与右侧由同一个稳定浮岛宿主装配，模式与右侧选择只改变实例的呈现位置：

```text
pages/workspace/components/
├── mainpanel/                 # 中央、右侧与停放状态共用的稳定浮岛宿主
│   └── chat-mainpanel/        # 聊天内容、空会话与输入区
├── leftpanel/                 # 模式入口、项目筛选与左侧导航
│   ├── chat-leftpanel/        # 项目与聊天列表
│   ├── file-leftpanel/        # 文件树、快速打开与搜索
│   └── changes-leftpanel/     # 工作区、暂存区与提交操作
├── rightpanel/                # 右栏选择器与内容
│   ├── chat-rightpanel/       # 上下文、Token 与 Git 概览
│   ├── file-rightpanel/       # 已配置的项目脚本任务
│   └── changes-rightpanel/    # 提交图及选中提交
├── topbar/                    # 会话标签及液态玻璃实现
└── PanelDividers.tsx          # 跨区域分隔条与尺寸拖动
```

区域 `index.tsx` 承担实际布局或内容组合，不保留旧位置的转发组件。文件编辑器、终端、对话渲染和共享 Provider 等业务能力继续由 `features/` 提供。左栏展开时，项目筛选位于模式栏与导航面板共同的顶部，横跨两列形成 π 形结构；项目名称与原生红绿灯垂直居中对齐，左侧留出按钮安全区，搜索按钮置于项目选择器右侧。侧栏收起后，项目筛选行高度归零且不显示搜索按钮（搜索入口仅在左栏展开时呈现），窗口级会话栏横跨顶行并保留完整的原生红绿灯安全区；模式栏保持 50px 宽，从第二行开始并以同一材质铺满到底，设置入口固定在底部安全边距内。项目筛选和顶行按钮排除窗口拖动，周围留白仍可拖动窗口。

## 外壳留白与根滚动

启动页与工作台只由主进程切换。启动窗口使用 760×480 插画，底部磨砂进度舱显示真实启动阶段；由于没有精确进度，横条保持不确定进度，启动完成后隐藏。工作台加载完成后清除主窗口的启动历史，禁止页面或浏览回退重新进入启动页；外部链接继续交给系统浏览器。会话订阅与内置网页只在主文档导航真正提交时清理，被取消的导航不得清空草稿或中断订阅。内置浏览器使用独立的导航历史，保留正常前进、后退。

Windows 窗口按钮随顶行状态切换位置：会话标签栏显示时，由 `Topbar` 在标签与新建按钮右侧渲染唯一的一组窗口按钮，标签区按剩余宽度伸缩或滚动；隐藏时由 `MainPanel` 放在右侧浮岛顶部，右栏收起或窄屏隐藏后由中央浮岛承接。顶行的按钮使用独立实色底保证透明画布上的可读性，落入浮岛时不再绘制底部横线切割（对话与空会话单窗格中透明叠加于主浮岛顶缘，使背景与滚出内容无缝延展至顶边），右侧浮岛不再保留重复的按钮行或分隔线。业务浮岛实例不随按钮位置变化重建。Windows 非最大化无边框窗口沿原生裁剪圆弧内侧补绘 1px 连续外轮廓，确保暗色主题叠在其他深色窗口上方时边界清晰可辨。

浮岛外壳 `.app-shell` 用 `position: fixed; inset: 0` 钉在视口上，四周留白由 `--window-edge` 给出；`html`、`body`、`#root` 只做裁剪（`overflow: clip`），不承担滚动。根链被滚动一次就会把外壳连同留白顶出视口：上边缘消失、底部多出等高的空白画布，看上去像“留白整体下移”。能越出视口的只有 portal 到 `body` 的浮层（Ant Design 的 Tooltip、下拉菜单、插件浮层），所以 `app.tsx` 在滚动和窗口尺寸变化时把根偏移复位。给外壳或它的祖先加 `transform`、`filter` 或 `contain` 会改变固定定位的参照，验收里的 `shellPinnedToViewport` 会因此失败。

## 维护范例：工作模式切换

工作台仍使用一个页面路由。左侧提供对话、变更、文件等工作入口；轨迹在聊天标签内切换，终端与浏览器从顶部新建菜单打开。

调用链如下：

```text
pages/workspace/components/leftpanel/WorkspaceToolbar.tsx
  点击模式按钮
        ↓
hooks/useWorkspace.ts → useWorkspaceStore()
  取得 Umi Model 持有的唯一状态实例
        ↓
models/workspace/store.ts → setView()
        ↓
models/workspace/view.ts → transitionWorkspaceView()
  计算模式与侧栏显隐变化
        ↓
Store 发布快照 → useWorkspaceSnapshot()
        ↓
pages/workspace/index.tsx / components/mainpanel/index.tsx
  更新布局属性与模式内容
```

- 改模式按钮、图标或排列：看 `leftpanel/WorkspaceToolbar.tsx`。
- 改某个区域在当前模式显示的内容：看该区域的 `index.tsx`，再进入对应业务面板。
- 改进入或离开模式的侧栏规则：先看模式贡献的 `collapsePanelsOnEnter`，再看 `models/workspace/view.ts`。
- 改浮岛位置、尺寸或已有过渡：看页面写入的 `data-*` 属性和 `styles/layout.css`。
- 改会话右侧选择恢复：看 `store.ts` 的 `sessionRightSelections` 与会话选择方法。主模式不按会话记忆，所有会话切换入口统一进入声明了 `sessionHome` 的模式；当前内置声明是对话。

进入声明了 `collapsePanelsOnEnter` 的模式时，会临时保存并收起左右栏；没有后续操作时，离开该模式恢复进入前状态。左侧导航模式（`navigationView`）与中央工作区视图（`activeView`）解耦：切换顶部工作标签、新建终端或浏览器标签只更新主区内容，不改变左侧导航面板与左侧模式栏高亮；只有点击左侧模式栏（或显式跳转入口）才切换左侧导航，进入 `plugins` 等整页模式不覆写既有 `navigationView`，离开时自动恢复原侧栏。内置的对话／轨迹切换位于聊天标签内，不再自动收放全局侧栏。用户在期间主动展开或选择右侧浮岛后，该选择成为新的右侧偏好，不会被旧快照覆盖。窄窗口始终隐藏右栏，放大后恢复原来的右侧偏好。`setView()` 只发布模式状态，布局样式负责侧栏收放。

右侧浮岛顶部使用 32px 方形图标标签，名称在悬浮或键盘聚焦时提示，不再常驻占宽。图标来自浮岛贡献。选中标签使用浅底色并始终保留在顶部；根据标签实际宽度决定可见项，放不下的项目收入“更多”菜单，不显示横向滚动条。左右方向键、Home 和 End 可切换可用标签。已在主区的实例从标签和更多菜单中排除，右端收起按钮独立固定。右侧一次只显示一个浮岛，选择新能力会直接替换当前内容，不维护前后层或成员列表；标签顺序来自贡献顺序，不随当前选择变化。模式的 `defaultRightIslandId` 只初始化尚未建立右侧选择的会话，之后切换中央模式不覆盖用户选择。右栏保留 Git、脚本和上下文检查内容；聊天、文件、终端、浏览器及 Git 差异统一通过顶部工作标签呈现。

“对话／轨迹”切换位于聊天浮岛右侧留白中的 28px 图标工具列，不再占用顶部整行，也不挤占底部仪表盘或放置重复的会话预设入口；隐藏右栏仍可使用。视图支持上下方向键、Home 和 End，名称通过提示与辅助名称保留。空会话的 Agent 预设选择统一留在空会话引导区中央胶囊内，开始后的预设锁定规则保持由核心决定。空轨迹会话不渲染无效的顶部控制按钮、空时间轴与“收起输入框”按钮；有记录后轨迹表为工具列保留独立侧边轨道。待办位于输入框正上方，与 DSH 的位置一致；不受右栏显隐、用量读数和窄窗口限制。为空时隐藏，有任务时显示默认折叠的状态计数，展开后按完成、进行中、待处理显示状态图标，清单在 180px 内滚动。任务内容来自同一份会话投影，只提供查看，切换会话后重新折叠。空会话、待建会话以及左侧栏收起时的对话视图在输入框正上方额外呈现工作区胶囊（及当前 Git 分支提示）：空会话下可直接切换目标工作区并迁移草稿与图片附件，左侧栏收起时的已有消息会话下用于切换工作区标签组、感知后台其他工作区的运行与未读更新或打开新目录。

文件视图只贡献主区位置；左侧项目树和消息文件引用都打开同一份文件工作区，使用顶部预览或固定标签、行定位与未保存保护。编辑器顶部路径栏显示当前文件路径的末尾三级，完整路径通过提示和辅助名称保留；底部仍负责文件导航与保存。删除右侧文件列表抽屉，避免出现两套文件入口。编辑器异步代码块在工作台挂载后延迟预热。

左侧提交消息框默认显示一行，可向下拖高。手动提交和 AI 提交并排放在输入框下方。文件总数和增删行数显示在同一块变更区的顶部，暂存和工作区列表紧接其下。左侧源代码管理和右侧 Git 检查栏的更改与图表均可独立折叠和滚动。两区展开时可拖动分隔线或用上下方向键调整高度，双击或按 Home 恢复默认比例。收起一块后，另一块使用剩余空间，再展开时恢复当前面板的比例。右栏的比较范围留在分区上方。

文件前进／后退、保存与 Git 的“并排／行内”切换统一使用 32px 底栏、28px 按钮和 12px 文字，公共尺寸与交互状态位于 `styles/view-tools.css`。Git 差异顶部显示当前文件路径；旧版／新版来源说明与布局按钮位于同一条底栏：旧版对应左列，新版从代码分栏中线开始，按钮独占右端轨道，文字与按钮垂直居中。正文与底栏预留相同滚动条槽，长路径和来源名称单行省略并保留完整提示。正文不显示来源标题及“旧版第几行／新版第几行”的分块定位条，但保留行号、增删标记、权限与文件变化说明；定位条在配对完成后移除，不影响跨块行号与增删配对。Git 正文拥有独立滚动区，底部切换始终可见；空差异和二进制文件不显示无效的布局入口。

这份右侧选择以会话为键，当前版本只保留在本次窗口生命周期内。重新启动 MyDSH 后按模式默认贡献重新建立选择，不把可能已经卸载或升级的插件标识写入磁盘。文件标签、编辑缓冲恢复和终端 PTY 生命周期由各自资源所有者管理，不依赖右侧选择序列化；跨重启恢复等前三阶段稳定后再单独设计版本与失效规则。

`WorkTabPanels.tsx` 为打开的业务标签保留稳定父节点；`mainpanel/index.tsx` 继续装配辅助浮岛。主区、当前右侧与停放只改变外壳类名、网格位置、`inert` 与传给贡献的呈现属性。普通右侧贡献切走后卸载；对话、文件和终端因有连续性需要，隐藏时继续挂载。插件卸载或作用域键变化仍正常销毁。这样文件编辑器在换位时保留标签、未保存正文和撤销现场，对话保留阅读位置，终端复用同一 PTY 界面，同时不为普通右侧面板保留无意义的后台渲染。

模式栏依托贯穿侧栏底部的沉降导轨，与底部设置入口共用同一垂直通道与 34px 按钮尺度，不再额外套外框；微玻璃选中层沿按钮顺序上下滑动，按压时显示内凹。选中图标使用主题强调色，键盘焦点有独立轮廓，强制色彩模式用系统选中颜色区分当前模式。工作台页面只对现有内容节点播放同方向的滑入，切换和卸载时取消旧动画，不复制视图或重建终端。侧栏展开比例由 `layout.css` 的可插值变量控制，中央区域与分隔条同步移动；尺寸拖动直接更新宽度，不经过收放过渡。隐藏侧栏使用 `inert` 排除交互，系统减少动态时关闭位移与宽度过渡。

浮岛表面通过底板、侧栏与主阅读区的明度阶梯、柔和外描边、顶部微光与落影区分层次。落影随间隙收窄，缝里仍可看见单独合成的画布。外沿保留连续描边，输入卡片使用轻浮起光学表面配合同心全圆胶囊底栏。左右分隔条的胶囊使用相同光向，按压与拖动时显示内凹，箭头和 22×48px 命中区域保持原尺寸。减少动态时取消形变，高对比度与强制色彩模式用清晰边界区分表面。

右侧浮岛只保留 260px 最小宽度，不设置固定像素上限。桌面布局根据当前窗口宽度、左栏实际占用和中央 420px 最小轨道计算可用边界；窗口缩小时只压缩实际显示宽度，持久化的用户宽度偏好保持不变，窗口重新放大后自动恢复。分隔条和二维拖动柄从当前实际显示宽度开始计算，避免缩窗后需要先拖过不可见差值。

### 窄窗口布局

窗口宽度不超过 1268px 时，隐藏右侧栏及其分隔条，正文和输入区使用释放后的宽度，不显示悬浮信息卡片或为它保留空位。右侧实例继续挂载并标记为隐藏、不可交互，终端和编辑状态保持不变。窗口放大后恢复原面板宽度与折叠偏好。

项目、模型、权限等浮层由 `AnchoredMenu` 沿触发方向展开和收回，收回时立即退出键盘与指针交互。右栏 Git 范围和基准分支保留原生选择语义，使用 Chromium 的自定义选项层完成过渡。减少动态时直接显示或关闭。

## 会话标签材质

工作台页面拥有唯一的搜索入口和 `SessionSearch` 显隐状态。该按钮仅在左栏展开时位于项目选择器右侧；收起侧栏后隐藏搜索按钮，不再迁入顶栏，此时会话栏横跨顶行并为原生红绿灯保留安全区，窄模式栏从第二行开始，不再占用红绿灯所在高度。关闭搜索仍将焦点返回当前按钮。搜索面板通过 CSS 从窗口顶部滑入，沿用请求取消和键盘行为；减少动态时由全局规则关闭动画。

左侧项目选择器与搜索按钮共用 28px 高度和垂直中心线，距顶部栏上下边缘各留 4px。悬停和菜单展开使用轻量底色，鼠标选择完成后不保留焦点底色；键盘聚焦使用内收轮廓，避免与浮岛描边相碰。

标签栏显隐由共享分组逻辑驱动（`work-tab-groups.ts`）：无论左栏展开或收起，当前分组仅 `0` 个标签或仅 `1` 个对话标签时均自动收起顶栏，改由主浮岛右上角内侧的轻液态玻璃浮动操作胶囊承载全页唯一的「新建工作标签」与「平铺选择标签」入口（macOS 左栏收起且顶栏隐藏时仍保留 32px 顶部透明安全行避让原生红绿灯；Windows 顶栏隐藏时整行归零，自定义最小化/最大化/关闭按钮顺移落入右栏或主浮岛顶缘）；打开第二个标签或唯一标签为终端／浏览器／文件／Git 差异／SSH 等非对话标签时平滑展开顶栏（macOS 回收浮动胶囊并将两枚入口归入顶栏右侧；Windows 因顶栏右侧由自定义最小化/最大化/关闭按钮占据，单/多标签均继续将两枚入口留在主浮岛右上角浮动胶囊内，避免紧邻窗口控制按钮误触）。顶栏隐藏期间，对话与空会话主区顶部叠加 `pointer-events: none` 的三层渐进式渐变模糊，顶端以实色渐隐彻底吸收滚出残影（减少透明回退柔和底色渐变，强制色彩隐藏）；浮动操作胶囊按主区视图自适应形态：在对话与轨迹单窗格视图下保持 36px 宽竖向形态并与下方会话工具列共用同一块完整玻璃外衣，从上到下依次承载「新建」「平铺选择标签」、分隔线与「对话」「轨迹」（Windows 窗口控制条落入主浮岛时胶囊整体紧贴其下方并保持 0px 接缝）；在终端、浏览器、文件、Git 差异、SSH/数据库及分屏视图下收敛为 34px 高横向胶囊，精准垂直居中于 42px 顶部工具栏最右端并由工具栏单独预留 84px 右侧轨道，不再延伸进下方内容或裁切原生 `WebContentsView` 与终端滚动条宽度（分屏右侧窗格为对话时，会话工具列顺移至其下方并保持右缘同轴对齐）。关闭当前项目分组中最后一个浏览器或终端标签时，不滞留在空浏览器或空终端占位页：优先切回同组剩余工作标签，若同组已无标签则直接回到首页欢迎的新聊天界面（且不向顶栏追加空白会话标签）。显隐过渡共用 `--session-chrome-reveal` 的连续进度：顶部网格行与间距展开时，右侧主内容及其分隔条同步下移；左栏展开时标签栏从第二列开始，左栏收起时标签栏横跨整行。顶部栏退出时立即设为 `inert` 并移出无障碍树，动画结束后隐藏绘制；快速反向切换由 CSS 从当前进度继续，减少动态时直接落位。标签按当前数量均分真实可用轨道，少量时铺满，多时同步收窄；最小宽度为 96px，不设置固定最大宽度，超过容量后横向滚动。窗口放大或关闭标签后重新计算，能容纳时收起滚动按钮，避免按钮本身占宽导致空白无法释放。长标题省略并保留完整提示。关闭按钮位于右端，预览文件为固定按钮单独留位，悬浮或聚焦不会改变标签宽度。溢出时使用固定圆角外框和 28px 左右滚动按钮，到达起点或终点时禁用对应方向；只在仍有隐藏标签的一端淡出内容，不再添加贯穿高度的直线边框。鼠标竖向滚轮映射到横向滚动，触控板横向输入保持原方向，Ctrl/Command 滚轮留给缩放；方向键浏览和选中切换都会让目标标签完整进入视野。减少动态时按钮直接滚动到位，高对比度模式移除边缘渐隐。

会话标签的业务入口位于 `topbar/index.tsx`，透镜由同目录的 `useSessionTabGlass.ts` 管理。`liquid-glass-web-react` 固定为 0.1.1 并随 renderer 打包，只折射无交互的材质层；标题、图标和按钮位于材质与透镜之上的独立前景层，不参与 SVG 滤镜。会话标签按项目分组，只渲染当前组的标签；侧栏收起时顶栏不再于左上角渲染额外的标签组切换按钮，工作区与标签组切换、后台未读更新提示与整组关闭改由对话输入框上方的工作区胶囊承接，非对话视图可通过平铺选择标签弹窗或标签右键菜单跨组切换与整组关闭，已打开的标签与当前焦点不变。分组切换沿用未保存文件保护，未读状态复用全局运行事件，不增加后台输出订阅。组内支持拖动和键盘排序，未选中标签悬浮或聚焦时显示轻微加深的底色。所有分组共用一个选中透镜；切换时透镜移动到目标标签，仅有小幅弹性，长按轻微收缩，不叠加第二层选中背景。形变通过该版本的 SVG `data-lens` 区域标记与外沿同步缩放，复用同一张位移图，升级库时需复验这些标记、实际折射和快速反向切换。减少动态时直接落位，减少透明与强制色彩时使用实色选中状态。

底轨使用实色，避免库的色彩通道合成把半透明背景变灰；折射强度按绘制区域宽度归一化，使不同窗口中的材质形变保持一致。上下绘制空间独立于 32px 栏高，允许透镜鼓起而不裁切外沿。

透镜到达左右边缘后，将弹簧越界量换成有上限的横向挤压和轻微纵向鼓起，按变形后的半宽约束中心，保持圆头在轨道内，再随弹簧复位。连续切换从当前位移继续；键盘激活与减少动态模式直接落位，不缩放文字或点击区域。

窗口移动使用 Electron 原生拖动区域：顶部无控件的留白、浮岛外侧留白和模式栏空白可移动整个窗口。标签仅将 26px 高的交互行设为 `no-drag`；52px 高的材质绘制容器保持可拖动，避免透明绘制留白挡住标题栏。搜索、新建等按钮独立排除窗口拖动；面板分隔条仍用于调整面板尺寸，操作系统最外沿仍保留原生窗口缩放。

标签拖动时跟随指针，相邻标签让出目标位置；释放后通过 `moveSessionTab` 更新已打开标签的顺序，当前会话与草稿保持不变。Escape、指针取消或窗口失焦会取消拖动；Alt 加左右方向键也可调整位置。点击仍调用受未保存文件保护的 `selectSessionTab`。排序只保存在当前工作台，不改项目会话列表。动画控制器不保存第二份选中会话；隐藏或卸载标签栏时释放引擎、指针捕获、观察器与动画帧。

## 对话轮次与阅读宽度

项目专注选择器仅显示图标、名称与箭头。在「全部项目」模式下，左侧工作区分组标题行以强调色左指示条、柔底描边与高亮文件夹图标明确呈现当前所属工作区的选中态（同步覆盖已有会话、空白会话、新建草稿以及终端／浏览器／文件等活动标签归属），与输入框上方工作区胶囊形成呼应。会话列表的长标题保持单行省略，通过 Ant Design Tooltip 在悬停或键盘聚焦时显示全文；Escape 关闭提示，拖动或打开菜单时隐藏。选中会话、按下行与拖动行分别使用选中标记、描边和抓手反馈，时间按内容占宽，操作按钮仅在悬浮或聚焦时占位，给会话标题保留主要空间。

`features/conversation/ConversationNavigator.tsx` 在内容区左侧按轮次显示刻度，摘要向右展开：悬停或键盘聚焦查看问答摘要，点击定位，上下方向键选择刻度。目录来自现有历史响应或 Session 概览中的公开 `turnOutline`，与 `projectConversation` 的已加载消息合并；目录缺失时只显示已加载轮次。定位较早轮次复用 `loadOlderHistory()`，分页失败后停止并允许重试，切换会话卸载旧定位。

随包核心的历史分页使用 `records`，分页合并后只保留规范 `events`，避免旧 `records` 遮住前插内容。刻度预览不读取工具结果和注入上下文，也不使用 DSH WebUI 的私有组件或状态。

`WorkspaceStore` 整批接受 `session/snapshot`，并使较早发起的历史请求失效；列表刷新不重新加载未切换的会话。打开标签的历史引用与阅读锚点由 Store 持有，关闭标签或销毁 Store 时清理；运行时载体重建时清除历史缓存并接受新基线。首次进入会话定位最新，切回时恢复原阅读位置；更新尾页只保留与新页连续的已加载历史。

会话列表刷新串行合并，刷新期间收到的新请求会追加一次读取；新建会话等待同一批刷新完成后选中结果，期间用户已切换项目或会话则保留用户选择。重复点击当前会话只恢复对话视图。完整回复到达后移除同一轮、同一步的临时 chunk；主内容区缓存历史的规范化结果，避免每个分片到达时重复预处理历史。

`ConversationFrame.tsx` 提供正文双侧宽度拖动，方向键微调、Shift 加速、双击或 Home 恢复自适应。对话宽度由界面自适应或正文拖动决定，外观设置不再提供重复的宽度滑块。`domain/panel-layout.ts` 将偏好保存在本机 renderer 存储中；`null` 表示自适应，手动范围为 640–1600px，实际宽度受当前浮岛空间限制。临时收窄窗口不会覆盖保存值；滚动控制在重新排版时保持阅读锚点或继续跟随底部。

代码编辑器与差异视图采用适合桌面阅读的固定 14px 字号、22px 行高及字体默认连字行为，不提供独立的代码排版开关。旧版外观文件中的代码字号、行高和连字字段继续兼容读取，但不再覆盖代码区域的样式；界面字号与用户终端字号各自保留原有语义。

正文与输入框共用 `ConversationFrame` 的宽度，拖动时同步变化。输入框默认高 112px，用户手动调整的高度仍按原偏好恢复。正文调节条默认隐藏，悬停或键盘聚焦时显示，按住后加粗高亮。面板分隔线复用既有 `is-resizing` 状态，即使指针尚未移动也给出按压反馈，松开或取消时恢复。

正文、过程摘要以及上下文、Think、工具行的整体共用左边缘，正文不为其他行的图标额外缩进。相邻过程行收紧间距，消息与过程组之间保留 16px 间距。中间回复和生成中的内容不显示复制、评价或时间戳；用户消息与最终回答保留消息操作，时间戳与操作同行。正文与 Think 共用界面字号基准（默认 12px，范围 11–18px），外观设置提供步进数字输入框直接调整；辅助元数据不低于 11px。回复中的一、二、三级标题分别比正文大 3px、2px、1px，其余标题保持正文字号，行内代码使用轻底胶囊与等宽字号校准。Think 展开内容中的标题保持次级文字大小，以粗体区分层级，避免浏览器默认标题字号放大。

运行过程保持可见；收到正常完成的 `turn/end` 且存在最终正文后，`ConversationView` 将同轮的工具调用、中间回复和最终回答中的 Think 收成可展开的过程摘要，最后一条正文独立显示。失败、中断和没有最终正文的轮次保留原展示。折叠只影响当前会话视图，不改写日志或轨迹数据。

模型恢复状态由同一步的 `llm/retry` 与 `llm/retry-started` 事件派生，显示在当前回复的等待位置，提供重试次数、计划时间及可展开的上次原因。停止继续使用输入区原有按钮；新输出、步骤结束或权威运行状态停止后移除恢复提示，不将它保存为助手正文。

用户消息气泡按正文自身宽度收缩并保持右对齐，左右内边距相等；下方复制按钮和时间戳的宽度不再拉宽短消息气泡。长消息仍受正文容器限制并正常换行。

用户气泡露出所在位置的对话背景，用左上柔光和右下阴影表现凸起。助手的表格、代码块、引用，以及思考和工具折叠块，用内阴影表现下凹，普通正文直接排在对话背景上。输入区底部的工具、选择按钮、发送和停止也用内阴影，停止按钮用中性底色和方形图标。发送中的临时等待与会话日志投影的等待状态交接，不写入虚构事件。常规等待回复时在像素矩阵旁按固定间隔平滑轮换加载文案，同时向辅助技术保留真实状态；减少动态时固定首句，出错重试仍显示真实重试信息。思考和工具运行时显示九点动效，完成后显示对应图标。流式正文最后一段显示方块光标，完成或中断后移除。减少动态时保留静态状态标记。工具折叠摘要做单行清洗，展开后保留原始输入和输出。

`apply_patch` 的完整工具输入可在展开后显示有界增删预览；预览明确表示请求内容，不推断文件是否已修改。输入无法解析或记录被截断时不生成预览，原有输入与工具结果仍可查看。

用户消息与最终回答的操作行在鼠标悬浮整条消息或键盘聚焦其中控件时显示，平时透明且不接收指针点击；始终保留行高，避免阅读位置跳动。不支持精细悬浮的触屏设备保留操作行，减少动态模式取消淡入淡出。

## 对话中的文件链接

`MessageMarkdown.tsx` 负责消息排版与链接呈现，`file-links.ts` 负责链接目标、项目相对路径和文件简称的纯解析；打开动作交给 `ProjectWorkspaceProvider.openFileFromConversation`，沿用文件标签、行定位和未保存保护，主进程继续核对项目边界与符号链接。普通点击在读取成功后把文件放在主区，当前完整对话移到右侧；文件读取失败或未保存保护取消时保留原来的内容与布局。

布局只在文件读取成功、来源会话仍然相同且操作期间没有新的手动右侧选择时提交。文件插件先捕获协同意图，读取成功后向工作台提交自身模式 ID 与目标位置；终端插件在“在主区打开”时走同一换位方法。工作台从模式贡献取得中央浮岛，检查目标位置仍可用，再完成换位。读取失败、未保存确认取消、贡献卸载或过期响应保留原布局。返回对话时只恢复本次协同占用前的右侧选择；协同后用户已经手动切换右侧时保留用户的新选择，不回放整份布局快照。

显式文件链接按目标路径打开，支持中文、空格编码和 `#L24` / `#L24-L30` 行号。链接识别不限制扩展名，项目内绝对路径先转为相对路径；项目外路径、越界路径和不支持的协议保持不可点击。可点击链接沿用 DSH Web 的正文语言：文件类型或网页图标置于文字前，静态状态使用链接色，悬停和键盘聚焦时显示点状下划线。文本、代码和图片沿用现有查看器，其他格式能否预览由查看器能力决定。

围栏代码显示语言标签、自动换行和复制按钮。默认在块内横向滚动，自动换行只改变显示；复制保留原始缩进和空行。

普通正文不自动识别文件名。行内代码只有在本轮已知文件中精确匹配或文件名唯一时才变成按钮；围栏代码、链接标签和生成中的回复保持原样。`session-file-references.ts` 从同一份 Session 日志投影每条回复之前成功的 `write`、`edit`、修改型 `str_replace_editor` 及 `deliverables/presented` 文件，不使用读取记录、失败调用或正文推测。实时传输与历史归一化保留 `surfaceOp`，工具结果只接受原始追加记录；缺少记录或存在同名歧义时不生成自动链接。

## 输入区工具

`features/composer/CommandPalette.tsx` 通过 Portal 显示命令与 Skill 候选，宽度不超过 420px，高度同时受 360px 和输入卡片上方可用空间限制。标题和搜索栏固定，列表单独滚动，键盘选中项始终保持在列表视野内。`/` 和工具组右端的 `>_` 按钮展示分类首页，不再单独显示 Skill 按钮；搜索独立于正文，选择候选只插入调用前缀并保留草稿。待发送图片在正文输入框上方以 64px 方形缩略图横排，超出宽度只横向滚动；文件名与大小放在悬浮提示，删除动作在悬浮或键盘聚焦时显示，触屏持续可用。工作模式按钮复用运行时 `/plan` 与 `/plan off`，启用后显示可直接退出的 Plan 胶囊与计划输入提示，当前状态来自 `plan` 投影，待生效选择明确提示下一步生效，不把正文或附件作为模式参数发送。

待确认计划按请求的 `plan-review` 意图呈现，不根据标题语言猜测。输入区保留摘要、“查看全文”、“要求修改”和“同意执行”；全文自动在右侧临时文档中渲染 Markdown，窄窗口使用中央阅读区。计划不占用右侧图标栏、更多菜单或默认栏目入口；阅读时仅显示文档标题与关闭操作，关闭后恢复原面板及折叠状态，切换会话不携带临时文档。历史计划从原消息打开。批准回传原请求指定的选项值，要求修改取消当前问题并返回输入区。普通问题与权限审批沿用原入口，受输入区高度上限约束。

附件入口使用回形针；输入框的图片粘贴与窗口拖放共用图片数量、大小、格式校验及主进程导入方法。图片成为可预览、移除的待发送附件，普通文本保留原生粘贴行为。命令开始后清空匹配的已提交草稿，输入区仅保留运行指示；对话视图将同一 `commandId` 的 `command/run` 与 `command/done` 合并成一行，呈现运行、成功或错误，长结果可展开。手动压缩根据 `compaction/summary` 展示真实压缩条数和 Token 数，并合并同次压缩的上下文注入。

模型菜单打开后按提供商（附官方品牌标志）直接列出下属模型，每行显示当前或默认推理等级。设置中心的「模型」页同样收敛为「提供商 → 模型」两级管理结构，提供商标志复用 `@lobehub/icons-static-svg` 收录的官方矢量 SVG 离线打包。悬停、点击模型行或按右方向键可以打开该模型的等级子菜单；选定等级后一次提交模型和等级。没有等级选项的模型可直接选中。子菜单优先显示在右侧，空间不足时显示在左侧；Escape 或左方向键返回模型行。选择失败时保留原选择和错误提示。权限菜单仍复用 `AnchoredMenu` 的定位和键盘导航。

## 输入区读数组

`features/composer/ComposerStatus.tsx` 在输入卡片**下方**单独占一行，`domain/session-hub.ts` 持有全部解析和格式化规则。数据只来自运行核心发布的会话投影：`tokenUsage` 的四个互不重叠计费桶（未缓存输入、缓存读取、缓存写入、输出）、`contextPressure` 的占用与容量、`sessionStats` 的轮次、步骤、耗时与解码速度，`contextBreakdown` 的构成估算，以及 `todos` 的整表快照。任一计费桶缺失时整份用量按不可用处理，不把半份账单显示成完整读数；上下文缺少任一侧读数时不给百分比；速度只在解码时长与提供方输出量同时为正时成立。

上下文百分比文字不封顶，超过容量时显示实际比例及“超过标称窗口”，只有图形封顶。原生压缩提交后，`awaitingUsage` 使旧占用读数失效，直到后续成功请求返回有效用量；`nativeCompaction` 区分请求检查点与本地保留历史，构成估算标注为非请求占用。自动摘要的 `compaction/end.error` 在对话中显示失败原因，轮次错误说明停止与恢复方式；取消不伪装成失败，手动命令沿用命令结果。

`ChatComposer` 在 Windows 与 macOS 都保留底部仪表盘，不因右栏展开而隐藏。会话还没有任何读数且不在产出时整条不渲染：新会话不出现“上下文”这类空占位胶囊，第一份投影到达后才出现这一行与它的面板入口；产出中的“统计中…”是唯一的无读数形态。读数按输入区容器的实际宽度降级：460px 以下收起轮次和缓存命中等附加文字，280px 以下只留图标，低于 180px 时才整条卸载。三个明细分别承载会话统计、累计用量和上下文占用，缓存写入只在大于 0 时显示。行高固定为 `--composer-readings-size`，外壳按这一高度为输入框、底部留白与缩放把手让位。

读数采用居中的轻量状态行：行高 24px，距卡片 2px，距浮岛底边内侧 6px；卡片高度保持原值，HUD 区域共占 32px。无读数时卡片仍使用 16px 底部留白。按钮悬停用浅底色反馈，展开时保持浅底色和正文色，键盘聚焦保留轮廓。点开各自的面板查看上下文占用、输出速度与 Token 合计。面板由 `shared/ui/AnchoredPanel.tsx` 按实际点击的按钮固定定位，默认向上展开；上下文、Token 与会话统计分别展示独立内容，同一时刻只展开一个面板。投影更新后重新定位，触发按钮消失时关闭。外部点击或 Escape 关闭并把焦点还给输入框；它不声明菜单语义，打开时不移动焦点。待办另置于输入框上方，展开后的清单限高滚动；智能体开启下一轮时清空。

读数组自身不持有会话，外层用会话标识重新挂载，避免读数跨会话残留。

## 会话预设与项目工具

内置会话预设收敛为标准模式（`standard`）、极简模式（`minimal`）和 ChatGPT（`gpt-coding`）三项；已下线的旧预设标识在恢复历史会话时自动映射兼容。实际工具暴露面、二级 `mydsh` 命令行与平台差异见 [编码与调度模式](agent-modes.md)，执行仍经过同一套 DSH 权限与生命周期。

Agent 预设只允许空会话切换；首次消息提交和等待启动期间禁用，开始对话后固定。选择器不会创建新会话，需要用户通过新建入口开始另一段对话。

空会话采用铺满底层的像素工坊稀疏网格微动背景（`PixelWorkshopBackground`），前景居中呈现标题说明与预设滑块，不再展示点阵徽章和起手建议卡片；背景随主题明暗与 `--accent` 自动配色，悬停与轻点空白网格提供柔和点亮与方形像素涟漪，在减少动态时仅绘制静态帧，在强制色彩模式下隐藏装饰画布。已有空会话的预设胶囊读取真实预设清单并遵守同一锁定规则；新会话在首条消息创建会话前不显示不可用的预设选择。

右侧 Git 可选择“未提交的改动”“上轮改动”“分支对比”。未提交范围复用工作区与暂存区列表；“暂存的更改”和“更改”标题可独立展开或收起，分组标题保留数量与批量操作入口，折叠不改变 Git 状态。批量取消暂存先确认普通暂存项数，保留未解决的冲突。执行时复核确认所依据的 Git 状态，变化后须重新确认。成功后展开工作区更改并显示结果。文件名优先占宽，目录仅使用剩余宽度，完整路径通过提示保留。“脚本”展示当前项目已配置的脚本及运行、编辑操作。终端跟随当前项目，切换项目时保留后台 PTY 与标签；任务仍发送给其来源项目。

## 权限胶囊

`features/composer/ComposerControls.tsx` 的权限胶囊按 DSH Web 的分工实现：**当前值**来自会话的 `permissions` 投影（`domain/session-controls.ts` 的 `parsePermissionCurrent`），**可选预设**来自运行核心的进程级目录 Remote `permissionPresets/catalog`（主进程 `listPermissionPresets` → `parsePermissionCatalog`），两者由 `permissionSelectionFrom` 合成。会话投影只发布当前值，所以缺省选项是正常形态，不把进程目录塞进每个 Session。

显示名按 `permissionPresetLabel`：内置键（read-only / workspace-write / danger-full-access / auto-review）用产品文案「仅可查看 / 工作区内修改 / 完全权限 / 自动审核提权」，部署自定义的名称保留并转标题式，不被内置文案顶掉。完全权限、自动审核提权及上游 Auto review 属于风险预设（`PERMISSION_RISK_PRESETS`），选中后收起菜单，在窗口中央打开独立的风险确认弹窗；说明、勾选与底部操作分别布局，勾选“我已了解风险”后才允许启用。Modal 管理焦点限制与 Escape 取消，关闭后焦点回到权限入口；取消、切换会话或目录撤销该选项都不会更改权限，也不保留上次勾选。

MyDSH 的 `auto-review` 保留 `workspace-write + ask`，只在单次提权审批前调用独立审核；它不使用上游 `auto` 的无沙箱执行组合。低风险且与用户任务一致的请求自动放行一次，其余转人工。后端机制和限制见 [自动审核提权](../packages/interaction/auto-review/README.md)。

错误面按 DSH Web 的分流：控件动作被拒绝（`selectPermissionPreset` 失败）写进 `snapshot.error`，由输入区的 `AppAlert` 呈现；目录加载失败则在胶囊自己的菜单里给出错误条与“重试”，与模型菜单的失败面同构；会话尚未报告权限或目录仍在读取时整块不渲染，不留永久加载态。

权限目录在流重置时重新加载，旧连接和组件卸载后的响应不再写回。当前权限由投影决定，目录先到或后到都与最新当前值合成。

权限控件调用的命令不占用输入区的命令状态；该状态只跟踪用户主动提交的斜杠命令。运行核心注入的权限变化通知仍保留给模型，桌面队列根据消息来源排除这类内部上下文，不计入用户的待处理消息。

数据库权限在数据库连接弹窗的「Agent 权限」标签中配置，输入区不提供独立授权按钮。连接默认关闭模型访问；开启后先选择只读、数据读写或完整访问档位，再按需添加表级规则。档位决定默认能力，表级规则只能进一步收窄。模型执行写入或 DDL 时，`PendingInteractionPanel` 通过 `mydsh-database-consent:` 请求显示完整 SQL、风险和目标并允许本次或本会话执行；档位或表规则不足时使用同一入口申请本次或本会话提权。提权不修改连接配置，绑定当前 Agent、连接版本和 SSH 依赖，会话结束、Agent 重建或连接改版后失效。库级 DDL、`DROP TABLE`/`DROP VIEW`、`TRUNCATE` 以及无 `WHERE` 的删改每次单独确认，确认卡只显示本次放行与拒绝。系统库、服务端文件和账号管理等硬边界不进入提权流程。

输入区按卡片实际宽度逐级收缩：先收起权限、普通模式等次要文字，模型名称使用剩余空间并以省略号截断；较窄时隐藏推理等级，只有卡片内容宽度不超过 300px 时模型入口才退为图标。完整模型名称始终保留在辅助名称和提示中。

## 状态和生命周期

Umi Model 在应用期间持有一个 `WorkspaceStore`。`initialize()` 获取初始设置与运行时状态并建立订阅；卸载时 `dispose()` 清理订阅。导航与输入区通过 `useWorkspaceSnapshot()` 直接订阅 Store 的快照。中央会话内容使用 React 的延后渲染快照：先更新标签和侧栏选择，切换期间仅内容区显示加载状态，再渲染历史。请求仍由 Store 按会话与代次校验，迟到响应不能覆盖当前内容。

会话切换还牵涉异步响应代次、草稿、事件顺序、队列和右侧选择恢复，当前继续由 `store.ts` 协调。切换目标会话时中央进入模式贡献声明的 `sessionHome`（当前为对话），右侧只恢复该会话记住的一个贡献标识，不复制插件业务数据。这个文件仍然较大；后续修改某项业务时应按真实职责逐项整理，避免再向它加入无关功能。

文件编辑与未保存导航保护由 `ProjectWorkspaceProvider` 管理，Git 投影、Diff 和写操作由 `SourceControlProvider` 管理，项目任务由 `ProjectTasksProvider` 管理。它们位于模式内容之外，切换模式不会重建。`TerminalWorkspace` 是窗口级唯一终端实例，按 `projectAccessId` 保留已经打开的 `TerminalView`；顶部项目标签只改变当前可见分组，不调用外层 `selectProject`。任务运行请求携带来源项目标识与名称，终端据此显示正确分组；来源项目切走后请求不会被清空。各分组上报标签数量，界面按窗口总数禁用新建，MyDSH Runtime 继续执行同一 12 个 PTY 硬上限。隐藏分组停止尺寸同步但不卸载，只有用户关闭标签或应用退出才结束对应 PTY。

终端贡献同时支持主区和右侧。右侧终端的“在主区打开”会把同一终端工作台移入中央，并把当前完整对话放到右侧；返回对话时恢复终端原来的右侧位置。直接点击终端模式只表达主任务切换，不自动把对话叠到右侧。终端已经在主区时，右侧候选不再显示终端，不能创建第二份终端工作台。

Runtime 退出或暂时不可用后保留工作台页面、文件修改和会话草稿，在页面显示连接状态。主进程统一拥有 Session 与运行时事件订阅；恢复后接受新的基线，不自动重放工具或其他有副作用的调用。订阅退出时释放逻辑流标记，允许后续会话选择重新订阅。项目任务的异步写入结果仅更新发起操作时的项目，项目切换会清除旧操作的忙碌状态。

运行错误依照日志里的 `turn/end` 显示在对应轮次：`error` 保留失败消息与错误码，`max-tokens` 提示回复达到输出上限，正常结束和用户取消不产生错误行。发送、命令、权限切换和附件操作失败使用页面顶部的红色浮层提示，可关闭并在 8 秒后消失；悬停或键盘聚焦时暂停计时，离开后继续剩余时间，不挤压输入区；权限目录读取失败留在权限菜单内供重试。浮层复用 `AppAlert`，通过 body portal 避免被浮岛裁剪；表单校验和需要原位处理的文件冲突继续使用内联提示。

## 桌面边界与构建

renderer 通过 `services/desktop.ts` 获取受限桌面桥，不直接请求任意服务地址，不导入 Node、Electron、主进程或后台运行时实现。主进程继续验证调用方、方法、参数和权限。现有 `host.call` 是保留的界面动作接口，由主进程转换为随包 Remote 契约，经 IPC 访问应用自有核心，不访问外部 Host。

生产构建使用内存路由与相对资源地址，生成 `lib/renderer/index.html`，由 Electron `loadFile()` 加载。页面仅允许本地应用脚本及 `mydsh-plugin:` 安装资源，不开放 `unsafe-eval`；sandbox、context isolation 和禁用 Node integration 的设置由主进程控制。

当前构建关闭 Webpack 的 `optimization.innerGraph`：实测该分析会把 xterm 的 `TaskQueue` 父类替换成 `null`，导致打开终端时崩溃。配置保留压缩和模块拆分；升级依赖后，必须通过真实终端验收再评估是否恢复该项优化。选项语义见 [Webpack 官方说明](https://webpack.js.org/configuration/optimization/#optimizationinnergraph)。

开发服务使用 `127.0.0.1:4175`。当前 Umi 忽略 `HOST` 对实际监听地址的影响，因此 `patches/@umijs__bundler-webpack@4.7.3.patch` 将配置中的 host 传入 `server.listen()`；pnpm 安装时自动应用这一行补丁。升级 Umi 时需重新确认监听地址，并在上游修复后移除补丁。

```sh
pnpm run setup:renderer     # 生成 Umi 的入口和类型，首次编辑前可执行
pnpm run typecheck          # 检查主进程、前端和测试类型
pnpm run test              # 使用现有 Vitest 测试
pnpm run build             # 构建主进程、preload 与 Umi renderer
pnpm run dev               # 完整构建后打开 Electron
pnpm run dev:renderer      # 仅前端开发服务器，缺少桌面桥时显示恢复提示
pnpm run check             # 类型、Lint、测试及工程门禁
pnpm run verify            # 隔离用户数据的真实 Electron 验收
```

`.umi`、`.umi-production` 和 `.umi-test` 是 Umi 生成目录，不能编辑或提交。Vite 仅作为 Vitest 的工具依赖保留，renderer 的产品构建统一由 Umi 完成。

## 浮岛插件与装卸生命周期

前端 Cordis 根位于 `plugins/react.tsx`，`MydshSlots` 服务管理普通插槽。`plugins/builtin.tsx` 只列出装配顺序；会话、文件、Git、本地终端、连接、浏览器、插件管理和设置分别在 `plugins/builtin/` 内注册各自的模式、浮岛及设置。模式声明中央浮岛、左侧导航、首次右侧建议及必要的 `sessionHome`、`collapsePanelsOnEnter`、`showComposer` 行为，当前右侧选择由外壳维护。Git 插件自行提供模式角标、数量提示、会话信息里的 Git 卡片和错误提示，Git 请求与状态由 `features/source-control` 持有；会话信息和页面提示通过插槽承接。布局、主题和焦点仍由外壳维护。

SSH 与数据库在模式栏使用独立按钮。SSH 左栏展示全部主机、搜索和管理操作，点击模式栏的 SSH 入口会在主区打开最近连接。左栏收起时，首页提供展开入口。搜索只过滤左栏。最近记录只保存成功连接过的主机标识。点击主机复用已有连接或发起新连接，首次连接仍先核对指纹。连接成功后打开窗口顶部的 SSH 工作标签，切到首页、聊天或数据库会保留 Shell，关闭 SSH 标签才断开。SSH 标签属于窗口，在不同项目中均可访问。连接期间用户切换标签后，迟到结果保留在后台，不抢走当前视图。编辑、测试、导入私钥、重新核对指纹和删除位于主机菜单。SSH 模式临时收起检查栏，保留左栏选择，离开后恢复用户布局。新增和编辑弹窗按连接信息、登录认证与其他设置分组。常规宽度采用双列，窄窗口改为单列，短窗口只滚动表单内容并固定标题和操作区。

数据库初次进入时不自动选择连接，左侧列出已保存的连接，主区展示快速开始（连接网格与顶栏新建连接、新建查询、刷新操作）和查询历史。新建查询先选择未停用的连接，历史记录点击后只恢复 SQL 草稿。成功查询在当前窗口最多保留 30 条，失败、取消和切换目标后的迟到结果不写入历史，历史不保存到磁盘。连接标题提供返回首页的入口，返回时取消当前请求并保留草稿。

数据库侧栏顶部同一行提供搜索框与紧凑图标按钮（新增连接、新增分组、刷新）。连接菜单可移动到分组，分组可折叠、重命名或删除。删除分组需确认，组内连接移回未分组列表。导航分组只在本地保存名称与连接标识，跨窗口同步，保存失败时保留输入并提示。搜索包含分组名称和已加载的连接、数据库、表，不触发远端读取。

数据库左侧按“连接 → 数据库 → 表／视图”展示可搜索的对象树，展开时按需读取；点数据库在右侧显示表列表，点表显示数据和字段结构，SQL 查询保留独立草稿。搜索仅过滤已加载的对象，不发起额外数据库请求。连接操作收在主区标题右侧菜单，分页和读取限制位于底部。窗口级常驻主浮岛继续拥有 SSH 终端与数据库状态；ConnectionsProvider 从当前模式推导分组，只协调左插槽目标，隐藏导航或切换 SSH／数据库不销毁终端、草稿和树的展开状态。数据库模式只临时收起检查栏，离开后恢复用户状态。关闭、删除、禁用或修改连接时由后台释放对应资源。主进程为允许的 `mydshSsh` 和 `mydshDatabase` 方法附加窗口凭证，renderer 不提供身份参数，也没有解密接口。已有密码、私钥与口令不回填表单，首次 SSH 指纹确认后即使认证失败也刷新记录版本。

MySQL 工作区通过实际 Remote 提供结构浏览、字段、100 行分页及手动单条受限 `SELECT`，工作区显示只读范围提示，并以分段控件切换表列表、数据、字段和查询。SQL 草稿按连接保留，切换目标取消原请求并忽略迟到结果；查询最多 500 行／2 MiB、单值 256 KiB，20 秒时限，取消通过同账号独立连接终止查询，无法确认时显示远端状态未知。大整数、Decimal、时间与二进制保持文本精度，NULL 单独标记。连接表单按连接信息、TLS/SSL、SSH 通道、「Agent 权限」、高级分区；新建连接默认关闭 TLS 和模型访问，开启模型访问后默认只读，可选择数据读写或完整访问并用 `库.表`／`库.*` 规则收窄。开启 TLS 时校验 CA 与服务器 DNS/IP 身份，身份留空默认使用连接地址；旧连接保留严格 TLS，失败不自动降级。SSH 使用已确认指纹的直接通道，不开放本机转发端口。模型可以从 `database_query` 或 `database_mutate` 发起变更；授权卡展示完整 SQL、目标与风险，越过档位或表规则时先申请本次或本会话提权。复跑正式界面及真实数据库验收使用 `node scripts/verify-connections.mjs --workspace`，只操作已有固定镜像中的隔离数据。

外观组件首次挂载时先禁用动效，再读取系统偏好，使 Ant Design 的 MotionProvider 从首帧保持稳定；切换减少动态效果不再重建工作台及其终端。全平台按钮由 `styles/buttons.css` 与 `shared/ui/AppButton.tsx` 统一提供与输入区发送／停止按钮同源的立体嵌压材质令牌（含明暗主题与高对比度／强制色彩降级），并通过 `ConfigProvider` 关闭两字中文按钮自动插空格。

Plan 审阅按核心的 `plan-review` 意图识别，在输入位置显示「计划待审」、标题、两行摘要以及「查看全文」「要求修改」「同意执行」。全文自动展开一次到会话作用域的计划浮岛，复用安全 Markdown 阅读器；窄窗口在中央显示文档并提供「返回对话」。关闭全文不回答问题，要求修改通过既有 `question-cancel` 恢复输入并保持 Plan 模式，批准使用核心原始选项标签提交。调用标识随受限投影传递，会话历史从同一份 `exit_plan_mode` 工具日志提供重新打开入口，不另外保存计划副本。迟到打开请求不能覆盖其他会话；关闭文档恢复之前的右侧选择，退出清理临时阅读状态。

插槽核心从固定上游普通插槽算法移植，支持 `single`、`list`、`keyed`，保留父声明所有权、声明代次、重复位置拒绝、级联释放和微任务通知。Cordis Service 的注册方法必须保留原型方法，保证 `this.ctx` 绑定到调用插件；改成箭头字段会导致贡献由外壳持有而无法随插件卸载。

普通中央浮岛互斥显示，右侧也只显示当前选择。对话、文件与终端浮岛声明隐藏时保留挂载，其他右侧贡献切走后卸载；只有主区或当前右侧可见且可交互。插件重新注册时错误边界按新贡献代次重建；当前右侧贡献被卸载后，外壳保留会话中的选择标识并临时显示默认贡献或其他可用贡献，同标识贡献恢复且仍支持右侧位置时再恢复。注册入口拒绝无效位置、作用域和组件元数据，模式或记忆中的贡献缺失、只支持其他位置或渲染失败时都只降级对应区域。

后台清单变更驱动 `FrontendPluginLoader`。主进程提供已验证的 `mydsh-plugin://<id>/<version>/<entry>` 和样式地址；加载器核对插件与版本，再通过外部脚本注册 CommonJS 工厂。工厂只解析宿主提供的 React、React DOM、Cordis 和 `@mydsh/ui`，其他依赖必须随插件构建。脚本、样式、订阅和 Cordis 副作用在卸载时清理，加载等待支持取消和超时。

设置弹窗使用独立顶栏统一对齐标题、配置文件入口和关闭按钮；顶栏不参与内容滚动，按钮采用 32px 高度并保留上下安全边距。窄窗口将分类导航移到顶栏下方，仍显示完整标题与关闭入口。

ChatGPT 订阅配置位于插件管理页的内置卡片中，在连接前说明身份、令牌及任务上下文的处理方式；首次启用后显示一次用量说明，确认状态由后台随注册保存。
尚未接入可验证的 SIWC 剩余额度数据，因此对话输入区和下方仪表行均不显示订阅额度入口或占位。
会话实际 Token 用量与上下文读数照常显示；插件详情页保留 ChatGPT 用量管理入口，不用这些读数推算订阅余额。

插件管理由 `mydsh.plugin-manager-ui` 注册为窗口级中央浮岛与左侧模式，进入时临时收起两侧，离开后恢复；不选中聊天标签或呈现会话输入区。设置中心不再单独保留“内置插件”或“ChatGPT 订阅”导航入口，内置插件配置与用户扩展管理统一由插件管理页面承接。内置插件和已安装扩展按卡片排列，可按分类和名称筛选；内置卡片点击进入终端、Agent 循环、子智能体、网页搜索或 ChatGPT 订阅配置。已安装插件显示真实清单、启停开关及状态，详情提供版本恢复和卸载确认。用户扩展贡献的设置页也可从「扩展配置」进入（内置的「浏览器与桌面操控」保留在设置中心，不混入扩展配置）。页面订阅清单变化，卸载页面释放订阅并忽略迟到的读取，操作失败保留原状态，资源占用显示重启后操作。

添加入口选择包含 `mydsh.plugin.json` 的本地 MyDSH 插件文件夹，经既有安装服务验证、暂存和装配。选择目录本身不执行插件，取消或窗口关闭后的结果不触发安装；安装前说明本机代码权限，安装失败保留路径用于重试。DSH 插件适配通过内置 `mydsh-plugin-development` Skill 与受控命令行 `mydsh plugin` 完成，不提供通用 WebUI 兼容层。开发接口和示例见 [界面插件指南](../src/renderer/src/plugins/README.md)。

已归档会话设置页复用工作台的 Session 与 Workspace 基线，按归档顺序倒序展示，可按标题和项目搜索。恢复动作经主进程白名单调用公开 `workspace/unarchiveSession`，与归档共用连接代检查和刷新路径；失败保留记录，成功后更新侧栏，不切换当前会话。每行提供复选框，全选作用于当前搜索结果；没有搜索时选择全部归档。搜索条件变化清空选择，批量操作只确认一次，成功项移除、失败项保持选中并可重试。删除逐条提交，最后统一刷新。永久删除使用红色按钮和确认弹窗，通过固定的 `mydshSessions/deleteArchivedSession` Remote 调用；归档使用 `mydshSessions/archiveSession`，先取消运行、清空队列并释放会话后再保存归档标记，已归档会话不会被后台读取重新激活。永久删除对旧归档的遗留任务执行相同的停止流程，停止或写入失败时保留记录。删除错误只在确认弹窗中显示，并去除 Electron 与 Remote 的技术前缀。会话所有者释放 Agent 与写句柄后，存储后端在写锁内删除日志全部代际，随后清理投影缓存、搜索索引和项目关联，最后移除归档标记。失败保留可重试的归档入口；删除后的刷新不再呈现该会话。该页通过内置设置插件注册，不加载 DSH WebUI。

## Windows 外壳

Windows 使用无框窗口，右侧浮岛顶部集成自定义最小化、最大化／还原、关闭按钮，以横线与业务内容分隔，外沿共用同一条浮岛描边；不增加独立按钮浮岛或整排空白。右侧栏收起或窄屏隐藏时，按钮移到中央浮岛顶部，业务插件实例仍保持原有父节点。按钮区域排除拖动并支持键盘焦点，按钮栏空白与外侧画布保留原生窗口拖动。系统快捷键与最大化继续由 Electron 窗口处理；边缘缩放由主进程的局部原生命中检测交给 Windows，关闭按钮经过既有未保存文档保护与退出清理。启动页共用按钮样式，启动小窗不能缩放或最大化；左侧项目选择器不预留 macOS 红绿灯位置。窗口状态通过 preload 版本 21 的固定窗口能力读取与订阅，只接受受信任的本地启动页或工作台主 frame，页面卸载和窗口退出时释放监听。

Windows 11 22H2 起使用原生 HostBackdrop 模糊背景，外观采用固定默认通透度（不再提供背景图片或画布透明度滑块）；浮岛与按钮底色保持不透明。背景视觉位于同一个 HWND 的 Chromium 内容下方，使用 WinRT 几何裁剪与窗口区域共用圆角；关闭越过窗口区域的整窗 Acrylic，避免圆角外出现浅色矩形。窗口保留正常缩放与最大化，不切换为透明分层窗口，不增加额外背景窗口。旧版 Windows 11、系统关闭透明效果、高对比度或原生调用失败时释放背景视觉并回到实色；减少透明与强制色彩继续覆盖画布和控件。默认验收在后台完成，可用 `node scripts/verify-source-runtime.mjs --foreground` 或打包验收的 `--foreground` 在隔离数据目录中补验真实最小化、最大化／还原，结束时清理退出。

Windows 关闭系统厚边框；普通窗口外角为 18px，浮岛圆角随窗口边距调整，使两层曲率的中心对齐。macOS 由系统裁切窗口，以 18px 近似计算浮岛圆角，不对页面重复裁切；当边距达到外角半径时，内角降为零。原生命中区域为圆弧的部分覆盖像素留出空间，Chromium 前景与原生背景共用同一条抗锯齿圆弧；窗口状态提供实际像素尺寸与半径，前景扣除分数缩放造成的视口取整余量。最大化及全屏使用矩形，还原和跨显示器移动后重新计算，并同步前景裁剪。原生合成不可用时收紧命中区域，保留可读实色。启动小窗进入工作台时显式恢复最大化能力。直边缩放区为 8 DIP，四角按到可见圆弧的距离命中对角缩放；宽度小于画布留白，不占用浮岛内的控件。Chromium 内容子窗口会绕过父 HWND 的窗口过程，必须同步处理其命中与悬停，让 Windows 接管缩放并保留系统水平、垂直和对角光标；固定启动小窗、最大化及全屏关闭缩放区，实色与高对比度继续保留缩放。只登记同一主进程线程拥有的窗口与内容子窗口，销毁、安装失败和退出时释放全部原生回调。

`node scripts/verify-window-shape.mjs` 默认在 150% 缩放下检查多尺寸、父窗口与 Chromium 子窗口的八个缩放方向、固定启动小窗、最大化及全屏，并以本次拥有的对比底窗逐像素检查四段完整圆弧、抗锯齿覆盖与圆弧外颜色泄漏，同时覆盖明暗主题、高透与实色降级；对比底窗先置于其他置顶窗口上方，再将测试窗口放在其上，避免背景被遮挡。关闭窗口后确认背景视觉与缩放回调数量归零，再清理隔离数据。UI 交付还须在 100% 和 150% 下真实悬停与拖动四边、四角；不能仅用角点、直边或正确的 `GetWindowRgn` 结果替代可见圆弧和鼠标验收。

快捷键提示按系统显示 Ctrl 或 ⌘；输入法组合事件期间保持原有输入保护。终端界面仅负责标签、显示与输入，关闭通过 Remote 等待后台的进程树清理，隐藏界面不会销毁终端。

点击停止只取消当前回复；普通会话通过既有 `session/cancel` 请求登记队列接续，等待旧驱动完成清理后使用新的取消信号执行后续消息。停止请求处理中禁止重复发送；退出、归档与目标暂停保持原有停止语义。

## 统一工作标签与编辑器

顶部工作标签栏常驻，混排当前项目的聊天、文件、终端、浏览器及 Git 差异，以图标区分类型，选中态跟随当前焦点。新建菜单通过点击或键盘展开，不响应悬停；菜单展开时再次点击按钮直接新建聊天，Escape 或点击外部收起；项目组菜单提供整组关闭。文件视图与终端视图不再重复绘制内部标签行。终端仅向 WorkspaceTabsProvider 发布导航描述与操作入口，PTY 仍由原终端组件拥有，隐藏、位置变化与标签切换不结束进程；关闭标签才进入原清理路径。后台聊天标签的关闭不抢走当前文件或终端，文件操作仍经过既有未保存保护。恢复其他项目的文件状态不自动抢走用户刚选择的终端或聊天。

文件查看器取消编辑器名称及路径标题区，正文使用 14px 字号、22px 行高、代码折叠与缩进操作；底部紧凑状态栏提供行列、UTF-8、语言、文件历史及保存。文件路径保留在顶部标签提示和无障碍名称中。明暗主题、强制色彩与原子保存、冲突处理保持共用。

底部会话仪表盘在两种桌面平台共用同一实现，显示轮数与步骤、输出速度、累计 Token 与缓存命中率、上下文占用。三个入口分别向上展开独立明细；上下文构成读取核心 contextBreakdown 的系统提示词、工具定义及对话消息估算，标注近似值，不把估算之和当作提供方锚定的占用总量。空间不足时先收起附加文字，再收为可展开的图标。

## 双窗格与文件附件

`WorkspaceTabsProvider` 保存平面的双标签分屏组、各组比例、焦点和浏览器标签描述；`useWorkTabs` 汇总现有领域的导航动作。拖拽到内容区左右边缘可组成固定分屏组，右键菜单与 Ctrl／Command+Shift+左右方向键提供同样的入口。组内点击只改变窗格焦点，不改变全局工作模式或侧栏；普通切换到组外标签会显示该独立标签，不替换原组成员；返回任一成员恢复原左右位置和比例。顶部两成员嵌套在同一个标签组容器中，横向拖动和 Alt＋左右方向键整体重排，其他标签只能放在组前或组后。每组最多两个成员，拖入第三个标签不接受分屏，预览提示后返回；组内成员拖到相反侧可交换左右位置及顶部顺序，原侧返回不变。菜单与快捷键不隐式替换成员。多个组独立保留，重新组合前须先合并原组，合并只拆指定组。位置与显隐变化不重建 PTY、网页或编辑器。可用内容宽度不足 720px 时保留组状态并只显示当前格；窗口较窄时检查栏临时让出宽度，不覆盖用户的折叠偏好。

标签向下拖出 10px 后显示跟随指针的预览卡：可见内容使用 inert 静态缩略并保留滚动位置和草稿，未挂载内容使用现有摘要，原生网页显示真实标题与 URL；不创建第二份业务资源。进入左／右半区显示两格落点并提前让位，松手或取消都有可中断过渡。中间分隔条支持拖动、方向键和双击恢复等宽。拖动时右检查栏临时让位，尺寸变化自动按最后的指针位置重算落点；原生网页立即隐藏，布局稳定后恢复，避免高频样式更新延迟遮挡处理。减少动态模式保留静态落点与操作反馈。

会话继续共用一个 WorkspaceStore。`SessionScope` 让每个聊天读取自己的草稿、历史、队列和待响应交互；可见的非焦点会话复用公开 `session/follow` 流，归一化逻辑位于 `shared/session-follow.ts`。文件草稿按打开文件保存，关闭预览和标签释放对应缓存。整组关闭先统一处理未保存内容，取消保留全部标签与草稿。

Ctrl／Command+W 关闭当前标签；Ctrl／Command+S 打开可搜索的标签平铺窗口，文件保存继续使用保存按钮。原生网页的快捷键由主进程按网页标签身份路由，弹层打开时隐藏重叠的网页视图。平铺卡片读取已有标题、类型和状态，不再挂载业务实例。

外缘与浮岛间隙固定采用官方 8px 默认值（历史外观配置文件中的间隙、背景图、画布配色与透明度字段保持兼容读取但不再覆盖界面投影）；画布底板采用中心与浮岛核心缝隙 100% 实色、向四边与四角平滑衰减至 84% 实色（约 16% 柔和通透）的椭圆径向渐变，避免浮岛核心缝隙透出背后窗口文字，在减少透明度与强制色彩模式下退回 100% 实色。浮岛分隔线悬停满 1 秒后延展，键盘聚焦和拖动立即反馈。正文宽度把手使用低对比中性色，不显示发光长线。对话滚动视口延伸至浮岛底部，输入区独立停靠；ResizeObserver 按输入区实际高度为正文留白，附件与待办展开后也不会遮住尾部消息。底部渐隐只覆盖正文，两侧留出滚动条槽，避免遮住滚动滑块。

普通文件拖入使用核心已有的 `fileUploads/upload`，读取用户提供的 File 字节并取得会话专属回执，发送时由 `session/prompt` 消费回执。附件保存在 MyDSH 私有数据目录，原文件不必位于当前项目内；`@file` 候选仍表示项目文件引用。图片沿用现有图片导入与校验。附件卡片显示上传、就绪和失败状态，失败可重试；核心重连后要求重新上传以获取新回执。普通附件受既有 64 MiB IPC 消息边界约束，单文件上限为 47 MiB，一条消息最多 16 个文件或图片。

本轮工作台验收入口为 `node scripts/verify-source-runtime.mjs --workbench`，使用现有隔离运行器验证拖拽、双聊天、双终端、双网页、文件未保存保护、整组关闭、归档多选，以及项目外附件的保存和消息投递。它是本次交互变更的聚焦验收，不代表外部模型成功回复或所有旧验收场景已通过。

## 轨迹审阅与内置浏览器

轨迹从同一份 Session 日志投影为 30px 单行记录表，超过 150 行使用窗口化渲染。时间轴支持等宽或真实时长、点击定位、区间筛选、滚轮缩放与重置；搜索、轮次和调用折叠不修改日志。右侧局部检查器提供概述、参数、结果、Schema、计时与原始记录，长 JSON 不在记录表内展开。底部保留共享输入区与会话仪表盘，切换对话和轨迹不丢失草稿，也不同时挂载两份输入区。缺少起点或工具定义时显示未记录，不推算时长或编造 Schema；上下文、嵌套调用、未完成模型尝试保留独立记录。复制保留完整原文，超长代码预览明确标出显示上限。

轨迹搜索和控制、三泳道时间轴以及检查器标签采用统一的凹槽与选中表面；选区仍由用户实际拖动产生。切到真实时长且记录有有效时间跨度时，标尺显示相对首条时间的读数；没有足够时间信息时只标识记录顺序，不虚构时间。

浏览器由主进程按标签 ID 拥有独立 WebContentsView，使用独立持久 Session、Chromium sandbox、context isolation，并关闭 Node、preload 和 webview 嵌套。固定版本的 browser 桥仅接收白名单动作，复核可信发送方与有限边界，导航只允许 HTTP(S)。网页不获得 MyDSH 的文件、终端或业务 IPC。隐藏保留网页，关闭释放进程；宿主重载、崩溃及退出释放网页。布局观察在菜单或弹层与网页区域重叠、栏目隐藏时隐藏原生网页，避免遮挡应用界面。工具栏统一采用 42px 高度，地址框内嵌「前往」提交按钮并在右侧配备独立「外部打开」按钮（窄分屏下自动收敛为高辨识度图标），全部按钮使用原生 `title` 提示以免浮层遮挡原生网页视口。下载和不支持的设备权限可转到用户明确打开的系统浏览器处理。

会话信息不再作为右栏入口。任务名称由顶部标签呈现，模型和权限位于输入区，上下文和用量明细保留在底部仪表盘。

Git 上轮审阅使用每轮首步前与工具收束后的工作区快照，取消和失败同样记录终点。快照存入 MyDSH 私有缓存对象库，不更改用户 Git 索引、提交或对象库；比较覆盖轮次期间的工作区变化，包含同时发生的人工编辑。旧历史没有快照时明确不可用。单次最多 20,000 个文件、单文件 32 MiB、累计 256 MiB，超限或失败不产生部分比较、不阻断 Agent。分支对比以共同祖先到当前 HEAD 为范围，不混入未提交改动；读取单文件时校验列表的比较标识，避免分支更新后显示不一致的差异。

设置中心不再保留单独的“内置插件”或“ChatGPT 订阅”分类页，导航收敛为通用设置、外观、模型、Agent 预设、已归档会话、浏览器与桌面操控 6 项；其中外观页仅保留界面字体、步进数字输入框字号（默认 12px）、主题色与缩放胶囊常驻。内置插件配置（含终端、Agent 循环、子智能体、网页搜索与 ChatGPT 订阅）及用户扩展的安装、启停和卸载统一由左侧独立“插件”页面（`PluginManager`）承接，常规内置参数字段与草稿处理由 `PluginConfigurationFields` 提供，ChatGPT 订阅以嵌入模式复用 `ChatGPTSettings`。
