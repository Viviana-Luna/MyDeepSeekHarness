# SSH 连接、远程终端与模型运维工具

`mydshSsh` 通过既有 Remote/Typert 提供连接配置、指纹核对、凭据保存与交互式终端；`@mydsh/ssh/tools` 是同包的模型工具入口，由 `@mydsh/cli-bridge` 在隔离作用域内装配并通过 `mydsh ssh` 二级命令行对外暴露，与人工终端共享认证与指纹边界，但使用独立的后台连接池与取消控制。

## 连接与安全模型

- **凭据与指纹**：连接配置与系统保护的凭据密文由现有 `CredentialProvider` 原子保存。密码、私钥和口令不进入公开状态、工具输出或 Agent 上下文。首次连接只探测主机指纹，用户确认后才允许认证；未确认指纹的连接始终拒绝 Agent 访问，指纹变化时立即阻止连接并撤销既有授权。
- **模型访问策略（「SSH」模式配置）**：每个连接默认关闭 `agentAccess`；开启后选择 `readonly`（只读）、`standard`（常规运维）或 `full`（完整访问）档位，可按需配置 `allowedPaths`（POSIX 绝对路径白名单）与 `allowSudo`（默认关闭）。
- **连接池与生命周期**：Agent 使用独立于人工交互终端的连接池，空闲自动回收；编辑、禁用、删除、重置指纹、会话释放和 Runtime 退出立即释放连接并撤销内存会话授权。

## 模型工具与授权流程

- `ssh_connections_list`：列出已启用、凭据完整、已确认主机指纹且向模型开放的 SSH 连接摘要与当前会话授权状态，不弹窗。
- `ssh_list_dir`：经 SFTP 列出远程目录内容并分页返回；受 `allowedPaths` 与远端 `realpath` 约束。
- `ssh_read_file`：经 SFTP 按行范围读取远程文本文件，拦截二进制与超大文件，输出受 48 KiB 字节预算限制。
- `ssh_write_file`：经 SFTP 精确替换或写入远程文本文件；写入前生成 Unified Diff 预览，经确认卡批准并复核远端 `mtime` 后原子落盘。
- `ssh_exec`：通过非交互式 `exec` 通道在指定 `cwd` 执行命令，返回退出码、耗时与头尾裁剪且脱敏的 `stdout`/`stderr`。纯只读白名单命令直接执行；其余变更命令或提权请求经确认卡批准；高危操作与 `sudo` 强制每次单次确认；毁灭性系统破坏命令直接硬拦截。
