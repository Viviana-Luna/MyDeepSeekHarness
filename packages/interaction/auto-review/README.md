# 自动审核提权

MyDSH 自有的审批答复器。输入区选择「自动审核提权」并确认风险后启用；默认仍是「工作区内修改」。它不同于上游关闭沙箱、逐次审核工具的 `auto` 集成，使用独立预设键 `auto-review`，始终保持 `workspace-write + ask`。

## 执行边界

- 工作区内原本允许的操作不增加审核。已有工具守卫、文件观察策略和私有配置保护继续生效。
- 仅审核从工作区沙箱到完全访问的**单次提权请求**。通过 `tools/execute` 的异步调用上下文取得实际冻结参数，核对审批的会话、调用 ID、工具名、目标权限及理由；不凭助手说明直接授权。
- 同一轮必须先观察到相同操作的沙箱拒绝。后台 Shell 的拒绝标记只是失败线索，不是安全证明；一次请求消耗该记录，同一操作在本轮不会重复自动授权。每轮最多处理 32 个不同操作，超出转人工。
- 覆盖普通 bash、pwsh、文件 write/edit，以及标准与 GPT 模式的 `exec_command`、效率模式的 Shell/写入接口。没有提权参数、无法关联后台失败、未知工具及组合程序仍走原有人工审批；不额外给它们开放权限。
- 审核模型复用当前会话路由，读取按来源标记的用户授权、项目约束与摘要，以及完整操作参数和工作目录，不使用主助手的历史系统提示词。授权上下文最多 96 KiB，总输入最多 128 KiB；超出预算或存在未理解的附件时转人工，不截断后放行。
- 取证仅开放 `stat_path`、`list_directory`、`read_text`，不开放 Shell 或网络；只读取受限范围内的小文本，拒绝已识别的凭据、符号链接和特殊文件。取证预算为最多 6 次、单次 16 KiB、累计 64 KiB，执行前再次核对证据是否变化。
- 结构化答复必须包含风险、授权强度、操作是否有界及原始人类指令的引用。保守策略只自动允许授权充分的低风险操作；均衡策略还要求只读取证，才可允许明确授权的有界中风险操作。高风险或授权不足转人工，严重风险或违反明确约束直接拒绝。
- 响应无效、提供商不可用或默认 60 秒超时会记录审核失败并停止本次操作，不把技术失败描述成安全风险结论。人工审批路径没有可用通道时，由原审批服务拒绝执行。
- 取消、用户指令变化、轮次或权限切换、插件卸载会撤回审核。模型迟到答复不能授权。`never` 仍在审批服务入口拒绝，不能被此插件绕过。

## 审计与恢复

`approval/asked` 和 `approval/decided` 仍由原审批服务成对记录。`approval/reviewed` 补充调用 ID、实际参数的 SHA-256、模型路由及自动/人工结论，不复制原始命令、密钥或模型自由文本。日志投影恢复任务上下文和权限选择；失败证据及单次授权不跨重启复用。插件缺失时，预设退化为工作区沙箱加人工审批，而不是完全权限。

## 局限

这是降低打断频率的实验性功能，不是安全证明。模型可能误判，且获准的那一次操作确实可能访问工作区外。文件沙箱不是全面的网络隔离；工作区内原本允许的破坏性操作也不由本插件额外审查。未知脚本、安装钩子、发布推送、敏感配置和不可逆修改按审核提示词要求人工处理，但模型规则不等价于操作系统强制限制。重要数据仍应备份。
