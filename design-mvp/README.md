# MyDSH MVP 统一视觉设计稿（Abyssal Glass · 深海折光浮岛）

本目录为 **MyDSH** 桌面端独立 HTML 视觉规范展示包，仅用于定稿产品 MVP 界面风格与流式动效质感，**不修改现有工程源码**，无任何外部网络或 CDN 依赖，直接用浏览器打开 `index.html` 即可离线完整体验。

## 预览方式

- 直接双击或刷新打开 `design-mvp/index.html`（支持 `file://` 离线加载，自动复用 `../assets/` 下的官方启动插画与应用图标）。
- **支持浏览器原生顺滑上下滚动**：全页从上往下依次排布 **10 座饱满独立的桌面界面画板（Artboards）**，滑动滚轮/触控板即可从启动加载页一气呵成浏览全部界面。
- 页面顶部的 **「MyDSH ✦ MVP 视觉稿」悬浮玻璃目录栏** 会在滚动时自动高亮当前画板，也可点击任意章节一键平滑定位，或实时切换 **深浅双色主题** 与 **光学调节滑块**。

## 核心设计理念

1. **五层深海光学阶梯（L0 ~ L4）**
   - **L0 深海画布（Canvas）**：支持透明度调节（`--canvas-alpha`）与对角漫射微星云，告别死寂纯黑背景。
   - **L1 光学浮岛（Island）**：三岛分离骨架，顶部内嵌 `1px` 镜面受光细边（`.island::before`），形成通透立体切面。
   - **L2 沉降微槽（Recessed Track）**：复用顶栏标签轨道的内凹阴影底座，统一用于左侧模式轨、空状态预设条、检查栏分段器与滑块轨道。
   - **L3 液态折射透镜（Liquid Lens）**：带顶部高光缘、SDF 边缘折射滤镜与阻尼弹簧滑动，贯穿顶栏标签、左侧 `50px` 模式导轨与开关控件。
   - **L4 悬浮光学指令舱（Composer Deck + HUD）**：聚焦外环星辉光晕、胶囊化权限/模型条与底部单行紧凑遥测仪表。
2. **克制型微像素流式动效（Subtle Pixel Motion）**
   - 像素/点阵仅作为微状态指示器与流式游标的点缀，对话流内部全部采用真实的 Agent 业务组件：
   - **空会话 15×9 点阵小徽章**：呼吸微光波纹 + 鼠标划过光迹涟漪；
   - **真实思考与工具调用链**：`思考` 折叠条、`读取文件` 芯片行与 `样式草案 Diff` 预览卡片，前导搭载克制的 `3×3` 微像素点阵图标与执行期迷你脉冲；
   - **无框流式正文与指令舱微动效**：正文词块依次显影配像素方块游标 `▋`、底部轻量复制/重试操作栏、发送钮旁 8 点阵微旋转环与单行紧凑遥测读数。
3. **同心曲率收敛公式**
   - 严格遵循 `内层圆角 = 外层圆角 - 间距`：外窗 `18px` → 浮岛 `12px` → 轨道槽 `16px` → 透镜/卡片 `12px` → 内部控件 `8px` → 模态对话框 `22px`。

## 目录结构

```text
design-mvp/
├── index.html               # 全画板顺滑滚动展示入口（含 SVG 折射滤镜与 1.65px 图标库）
├── README.md                # 视觉设计说明与工程映射表
├── styles/
│   ├── tokens.css           # 深浅双主题色彩、同心圆角、五层光学阴影与字体 Token
│   ├── shell.css            # 窗口画布、三浮岛骨架、顶栏标签透镜、模式导轨与光学指令舱
│   ├── views.css            # 启动加载页及 10 座业务画板视图样式
│   ├── pixel-motion.css     # 熏黑点阵信标、算力波形、去噪收敛沙盒与 Token 流式解码样式
│   └── overlays.css         # 顶部画廊导航条、搜索窗、总览窗与设置中心双胶囊液态滑块
└── scripts/
    ├── glass-engine.js      # 多轨道 SDF 折射贴图、标签透镜弹簧动力学与液态滑块拖拽引擎
    ├── pixel-stream.js      # 点阵星芒信标交互、三浮岛去噪收敛画布与 Token 逐块流式播放器
    └── showcase.js          # 滚动高亮联动、启动阶段切换、SSH/数据库侧栏切换与模态交互
```
